# EvalAgent 手工测试用例

> 前置条件：项目一 FastAPI 已启动（http://127.0.0.1:8000），本项目 `npm run dev` 已启动（http://localhost:5174）。
> 测试账号：管理员 `admin` / 普通用户（项目一数据库中的 role=user 账号）。
> 测试浏览器：Chrome / Edge 最新版。

## 一、鉴权与权限控制

| 用例编号 | 用例名称 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| TC-01 | 未登录访问业务页 | 未登录状态直接访问 http://localhost:5174/dataset | 自动跳转到本项目 /login 页 |
| TC-02 | 管理员登录 | 输入项目一管理员账号密码，点击「登录」 | 登录成功，跳转数据集页，侧边栏显示「管理员」角色标签 |
| TC-03 | 密码错误 | 输入错误密码登录 | 提示「用户名或密码错误」，不跳转 |
| TC-04 | 普通用户访问受限页 | 普通 role=user 账号登录后手动访问 /task 或 /ab-compare | 提示「权限不足：该页面仅管理员可访问」，跳转 /settings |
| TC-05 | 普通用户隐藏写按钮 | 普通用户进入任意页面 | 无「创建评测任务」「创建数据集」等写操作入口 |
| TC-06 | token 过期 401 | 登录后在项目一后台删除该会话（或等待过期），刷新页面执行任意请求 | 提示「登录已过期」，自动跳转项目一登录页（VITE_LOGIN_URL） |
| TC-07 | 退出登录 | 设置页点击「退出登录（清除本地凭据）」 | localStorage 中 evalagent_token 被清除，跳转 /login |

## 二、数据集管理 /dataset

| 用例编号 | 用例名称 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| TC-08 | 上传合法 CSV | 选择知识库 → 填名称 → 上传表头为 `question,ground_truth` 的 UTF-8 CSV（如 10 行） | 提示「解析成功：10 条有效样本」，点提交后创建成功并出现在列表 |
| TC-09 | 上传非法表头 CSV | 上传表头为 `q,gt` 的 CSV | 前端提示「表头必须为 question,ground_truth」，不发起请求 |
| TC-10 | 上传空文件 | 上传空 CSV | 前端提示「CSV 文件为空」，拒绝入库 |
| TC-11 | CSV 中 question 为空 | 某 question 列留空 | 该行被拒绝并逐行提示，有效行仍可提交 |
| TC-12 | 超过 500 条 | 上传 501 行 CSV | 提示超过上限，拒绝提交 |
| TC-13 | 非 CSV 文件 | 上传 .xlsx / .txt | 提示仅支持 .csv |
| TC-14 | 样本分页预览 | 列表点「预览样本」，翻页 | 对话框内 question / ground_truth 分页展示正确，页码与总数一致 |
| TC-15 | 删除按钮 | 管理员查看数据集列表「删除」按钮 | 按钮置灰，tooltip 说明上游无删除接口（不发起请求） |

## 三、评测任务 /task

| 用例编号 | 用例名称 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| TC-16 | 创建评测任务 | 点「创建评测任务」，选数据集，填 chunk_size/search_mode/top_k，提交 | 提示任务已创建，列表出现 pending/running 记录，实验配置列显示 rag_config 参数 |
| TC-17 | 进度条轮询 | 任务 running 时停留列表页 | 每 5 秒刷新，进度百分比=已完成样本数/总数，完成后变「已完成」 |
| TC-18 | 按状态筛选 | 状态下拉选 done | 列表仅显示已完成任务 |
| TC-19 | 任务详情 | 点「详情」打开抽屉 | 展示评测模型、四项指标汇总、得分分页明细（question/answer/contexts/四指标/延迟） |
| TC-20 | BadCase 筛选 | 抽屉内打开 BadCase 筛选开关，阈值 faithfulness<0.6 | 明细仅保留 faithfulness<0.6 或 context_recall<0.6 的样本，计数正确 |
| TC-21 | 导出 CSV | 对 done 任务点「导出 CSV」 | 浏览器下载 eval_run_{id}.csv，Excel 打开中文不乱码（上游带 BOM） |
| TC-22 | 未完成任务禁用详情/导出 | pending 状态任务 | 「详情」「导出 CSV」按钮禁用 |

## 四、A/B 实验看板 /ab-compare（核心）

| 用例编号 | 用例名称 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| TC-23 | 下拉只列 done 任务 | 打开 A/B 页查看任务下拉 | 仅出现状态=已完成的评测任务 |
| TC-24 | 同任务校验 | A、B 选同一个任务，点「开始对比」 | 提示「不能选择同一个任务」 |
| TC-25 | 跨数据集拦截 | 选择两份 dataset_id 不同的 done 任务，点「开始对比」 | 弹窗「数据集不一致」，不请求明细接口 |
| TC-26 | 正常对比 | 同一数据集两份 done 任务，点「开始对比」 | 出现 ECharts 柱状图（4 项指标 A/B 并排），汇总表显示差值（B-A） |
| TC-27 | 差异标黄 | 存在 \|Δ\|>0.1 样本的数据 | 样本对比表格中对应行整行黄色底色（#fffbe6），Δ 列显示正负号差值 |
| TC-28 | 样本对齐 | 两侧 question 一一对应 | 每行左右分栏展示 A/B answer 与分数；某侧缺失时显示「无对齐样本」 |
| TC-29 | 前端分页渲染 | 样本较多（>20 条） | 表格每页 20 条，翻页流畅无卡死 |
| TC-30 | 导出 Markdown 报告 | 点「导出 Markdown 报告」 | 下载 ab_report_runX_vs_runY.md，含实验配置说明、汇总指标表、差异样本列表 |
| TC-31 | 无差异报告 | 两组结果接近时导出 | 报告显示「两组结果高度一致，无显著差异样本」 |
