# 边界异常测试用例清单

> 适用项目：企业垂直知识库 Agent 后台（FastAPI + LangGraph + DeepSeek）
>
> 说明：
> - 所有接口统一返回 `{code, message, data}`；成功 `code=0`，失败 `code` 与 HTTP 状态码对齐。
> - 「结果」列在执行时填写：✅ 通过 / ❌ 失败 / ⏳ 未执行。
> - 本清单为功能验收用例（非负载/性能测试）。
> - 前置账号：管理员 `admin`、普通用户 `user`（两套账号由冒烟脚本或后台创建）。

## 附：统一响应体校验

每个用例除业务断言外，均需校验响应体结构严格为三键：

```json
{ "code": <int>, "message": "<str>", "data": <object|null> }
```

- 成功：`code=0`、`message="ok"`（或业务提示）、`data` 为业务对象。
- 失败：`code` 与 HTTP 状态码一致（401/403/404/409/422/500/502/504），`data=null`。
- 全局异常处理与 JSON `charset=utf-8` 由 `app/main.py`、`app/core/exceptions.py` 保证。
