## 通用约定

- **统一响应体**：所有接口返回 `{"code": 0, "message": "ok", "data": ...}`；失败时 code 非 0、data 恒为 null。
- **鉴权方式**：除登录/刷新/健康检查外，均需 `Authorization: Bearer <access_token>`。
- **双 Token**：access_token 30 分钟（Redis session，滑动过期），refresh_token 7 天（一次性轮换 + 登出拉黑）。
- **错误码口径**：400 业务校验失败；401 未登录/令牌失效；403 已登录但权限不足；404 资源不存在；422 参数校验失败；500 服务器内部错误。所有错误响应头均携带 `X-Trace-ID`（与服务端日志 trace_id 对应）。
- **Trace 链路**：网关/前端可传 `X-Request-ID`，后端复用为全局 TraceID；未传则自动生成，回写于响应头 `X-Trace-ID`，全部日志自动携带。

## 附：请求/响应示例（关键新增接口）

### POST /api/v1/auth/refresh-token（刷新令牌，一次性轮换）
```json
// 请求体
{"refresh_token": "xxxxxxxx"}
// 成功响应
{"code": 0, "message": "ok", "data": {"access_token": "新访问令牌(30min)", "refresh_token": "新刷新令牌(7天)"}}
// 失败响应(401)：令牌无效/过期/已拉黑
{"code": 401, "message": "刷新令牌无效或已过期", "data": null}
```

### POST /api/v1/auth/logout（登出 + 刷新令牌拉黑）
```json
// 请求体（refresh_token 可选，推荐传入实现踢下线）
{"refresh_token": "xxxxxxxx"}
// 成功响应
{"code": 0, "message": "ok", "data": {}}
```

### POST /api/v1/eval/runs/compare（A/B 两两对比）
```json
// 请求体：两个运行必须属于同一数据集
{"run_id_a": 1, "run_id_b": 2}
// 成功响应（节选）
{"code": 0, "message": "ok", "data": {
  "run_a": {...}, "run_b": {...},
  "summary": [{"metric": "faithfulness", "avg_a": 0.52, "avg_b": 0.68, "diff": 0.16}],
  "rows": [{"question": "q1", "a": {...}, "b": {...}, "diffs": {"faithfulness": 0.7}, "is_diff": true}],
  "diff_threshold": 0.1}}
// 失败响应(400)：非同一数据集
{"code": 400, "message": "两个评测运行必须属于同一数据集", "data": null}
```

### GET /api/v1/eval/runs/{run_id}/badcases（BadCase 分页）
```
GET /api/v1/eval/runs/1/badcases?metric=faithfulness&threshold=0.6&page=1&page_size=20
// 成功响应（节选）：NULL 指标不参与筛选（统一空值口径），按指标升序（最差在前）
{"code": 0, "message": "ok", "data": {"total": 3, "page": 1, "page_size": 20, "items": [
  {"question": "...", "ground_truth": "...", "answer": "...", "retrieved_contexts": [...],
   "faithfulness": 0.32, "answer_relevancy": null, "context_precision": 0.55, "context_recall": 0.41}]}}
```

### GET /api/v1/eval/runs/{run_id}/stratum_metrics（分层指标聚合）
```json

  {"stratum": "难例", "sample_count": 5, "metrics": {"faithfulness": 0.61, "answer_relevancy": 0.72, "context_precision": 0.58, "context_recall": 0.66}},
  {"stratum": null, "sample_count": 7, "metrics": {...}}]}}
```
