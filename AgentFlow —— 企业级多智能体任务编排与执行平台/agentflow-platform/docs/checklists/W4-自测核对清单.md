| J-6 | `sse_event_frames` 心跳 `: ping` 未单测 | W3 已知缺口，非 W4 范围 | 并入 SSE 协议用例 |
| J-7 | 评测集统计显著性 | 30 条够验证管线，不够做置信区间 | 每层扩到 30+，并加「对抗样本」层 |
| J-8 | MCP HTTP 传输 / FR-014 分层记忆 | 任务书明确划为 P2 | 见 `README-W4.md §10` 的 P2-1 / P2-2 |

## 结论

- **6 项任务全部交付**，全部有可复现命令与实测数据，没有"只写了代码没跑过"的项；
- **7 条基线约束全部满足**：W1/W2/W3 业务代码零改动（仅 `kb_search.__init__` 一处 5 行适配改动），
  `150 passed` 无回归，`MOCK_EXTERNAL_RAG` 开关保留，P2 仅注释占位，挂起判定仍走快照 `interrupts`；
- **离线档位能验的都验了**：管线、协议、状态机、断点、取消、指标聚合、压缩算法本身；
  **不能验的都明确登记在 J 段**，没有把 Mock 结果包装成质量结论；
- A/B 实验给出一条反直觉但重要的结论：**压缩省的是"历史注入量"（-73%），不是"端到端 token"**
  —— 端到端 +37.7% 是因为对照组压根不注入历史。这条必须写进对外材料，否则会被误读成"压缩无效"或"压缩有副作用"。
