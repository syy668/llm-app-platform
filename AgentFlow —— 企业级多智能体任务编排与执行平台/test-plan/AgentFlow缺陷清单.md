## D-02（P2 · 设计观察项 / 建议项，非功能缺陷）

| 字段 | 内容 |
|---|---|
| 缺陷ID | D-02 |
| 模块 | 模块2 工具注册表功能 |
| 现象 | 当 4 个工具全部被禁用时，`filter_enabled_tools` 触发 fail-open 回退、**返回全量工具列表**，编排不会因"全禁用"而真正禁用工具，也不会报错或产出空计划。这与"禁用全部工具→无工具可用"的直觉预期不符。代码注释明确此为安全设计（注册表异常/全禁用时不阻断生产），属有意行为。 |
| 复现步骤 | 1. admin 依次 `PATCH /api/v1/tools/{name}`（`enabled:false`）禁用全部 4 个工具；2. 创建并执行任务；3. 观察 Planner 工具列表/轨迹 → 被禁用工具仍可被规划调用。 |
| 建议 | 与产品确认预期语义：<br>(a) 若期望"全禁用即无工具可用" → 改为 fail-close（全禁用时让任务明确报错或跳过工具步骤）；<br>(b) 若维持 fail-open（安全优先）→ 在工具管理界面与 `GET /tools` 响应中明确提示"全部禁用已自动回退全量工具"，避免运维误判。<br>当前记为**观察项/建议项**，非功能缺陷。严重等级 **P2**。 |
