## 环境性说明（非缺陷）

| 编号 | 说明 |
|---|---|
| NOTE-01 | 四路问答 / SSE / RAGAS 评测依赖真实 DeepSeek（`LLM_API_KEY`）；未配置时 Agent 侧 `get_llm()` 抛错并映射为 502/评测失败。 |
| NOTE-02 | `LLM_PROVIDER=mock` 仅作用于 RAG 直答（`app/rag/llm.py`）与 embedding，不影响 LangGraph Agent 路由。 |
| NOTE-03 | `FAKE_REDIS=true` 用 fakeredis 内存模式，便于本地/CI 无 Redis 环境跑通鉴权链路。 |
